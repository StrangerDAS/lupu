## Overview

LUPU is a vehicle rental platform where owners can list vehicles (bikes, scooters) and customers can rent them. The system consists of a Vite+React frontend and an Express+Mongoose backend, utilizing Firebase for authentication and media storage.

```
┌─────────────────────────────────────────┐

├─────────────────────────────────────────┤
│        Backend (Express.js API)         │
│  (Business Logic, Auth Middleware)      │
├─────────────────────────────────────────┤
│    Database (MongoDB / Mongoose)        │
│    Storage/Auth (Firebase Admin)        │
└─────────────────────────────────────────┘
```

## Components

### Frontend
- **Purpose:** User interface for customers to browse vehicles and owners to manage listings.
- **Location:** `frontend/`
- **Dependencies:** React, Vite, Tailwind CSS, Zustand (state), React Router, Firebase Client SDK.

### Backend API
- **Purpose:** Handles business logic, API endpoints for vehicles/users, and data validation.
- **Location:** `backend/`
- **Dependencies:** Express, Mongoose, Firebase Admin SDK, Multer.

## Data Flow

1. User authenticates via Firebase on the frontend.
2. Frontend sends requests with Firebase JWT tokens to backend.
3. Backend validates JWT using Firebase Admin SDK and maps it to a MongoDB user record via `authMiddleware.js`.
4. Backend retrieves/updates data in MongoDB via Mongoose and returns JSON to frontend.
5. Media uploads (e.g., vehicle photos, KYC) go directly from frontend to Firebase Storage, then URLs are saved to MongoDB. Some vehicle documents fallback to backend `multer` upload.
